# ScreenThai

**แปลหน้าจอเป็นภาษาไทยแบบซ้อนทับโดยตรงบน Windows — ไม่ต้องใช้ OBS**

แอปเดสก์ท็อป Python / PySide6 จับภาพจอ → OCR ในเครื่อง → AI เลือกและแปลข้อความ → วาดภาษาไทยทับตำแหน่งเดิม โดยเมาส์คลิกทะลุ overlay ได้ ไม่ inject โค้ดเข้าเกมและไม่ต้องใช้สิทธิ์ Administrator

> **สถานะ: รุ่นเริ่มต้น 0.1.0 สำหรับทดลอง** มีโค้ดทำงานจริง ไม่ใช่หน้า mockup แต่ยังไม่ได้ทดสอบ end-to-end กับเกมบน Windows จริงหรือบริการ AI จริงในสภาพแวดล้อมนี้ ไม่รับประกันความเร็ว real-time หรือความถูกต้องของ AI และยังไม่ครบทุกฟีเจอร์ขั้นทดลองในคลิป โดยเฉพาะเสียง/ใบหน้า/อ่านปาก

## เริ่มใช้บน Windows

### วิธีที่ 1: รันจากซอร์ส (พร้อมใช้ใน repository นี้)

1. ติดตั้ง **Python 3.11 x64** จาก [python.org](https://www.python.org/downloads/windows/) โดยเปิด Python Launcher (`py`)
2. ดาวน์โหลด/แตกไฟล์โปรเจกต์ แล้วดับเบิลคลิก **`Start-ScreenThai.cmd`**
3. ครั้งแรกสคริปต์จะสร้าง `.venv` และติดตั้ง dependencies จากอินเทอร์เน็ต ครั้งต่อไปไม่ติดตั้งซ้ำ
4. ตั้งค่า AI ตามหัวข้อถัดไป แล้วเปิดเกมแบบ **Windowed หรือ Borderless**
5. เลือกจอ → ทั้งจอ/ลากพื้นที่ → เลือกข้อความทั้งหมดหรือบทสนทนา → กด **เริ่มแปลหน้าจอ**

หากเปิดไม่ได้ ติดตั้ง [Microsoft Visual C++ Redistributable x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist) และดู error ในหน้าต่าง CMD ไม่มีการซ่อน error ระหว่างติดตั้ง

### วิธีที่ 2: สร้างแอป `.exe` แบบ portable

ยังไม่มีไฟล์ `.exe` ที่สร้างและตรวจสอบแล้วแนบมาในรอบนี้ มี build script และ GitHub Actions เตรียมไว้:

```powershell
# รันจากโฟลเดอร์โปรเจกต์บน Windows ที่ติดตั้ง Python 3.11 x64
powershell -ExecutionPolicy Bypass -File scripts/build-windows.ps1
```

ผลลัพธ์: `dist/ScreenThai-Windows-x64.zip` แตก **ทั้งโฟลเดอร์** แล้วเปิด `ScreenThai.exe` ไม่ต้องติดตั้ง Python บนเครื่องปลายทาง แต่อาจต้องมี Visual C++ Runtime และต้องมีบริการ AI แยกต่างหาก **อย่าย้ายเฉพาะ exe ออกจาก `_internal`**

หรือเปิด GitHub → Actions → **Windows build and tests** → Run workflow บน branch งานนี้ เมื่อ build ผ่านจึงดาวน์โหลด artifact `ScreenThai-Windows-x64` ได้ Workflow นี้ยังไม่ได้ถูกสั่งรันจาก session นี้

ตัวแอปยังไม่มี code signing ดังนั้น Windows SmartScreen อาจเตือน ตรวจแหล่งที่มาของไฟล์ก่อนใช้งานเสมอ

## ตั้งค่า AI

### Local AI ในแอป (ไม่ต้องติดตั้งอะไรเพิ่ม)

แท็บ **Local AI (llama.cpp)** ทำให้ครบในโปรแกรมเดียว: ดาวน์โหลดไฟล์ `llama-server` → ดาวน์โหลดโมเดล `.gguf`
จาก Hugging Face (มีแคตตาล็อก + ช่องพิมพ์ repo เอง) → กดเริ่มและกด *ตั้งเป็น AI ของแอป*
เซิร์ฟเวอร์ผูกกับ `127.0.0.1` เท่านั้นและปิด web UI ทุกครั้งที่มีการเชื่อมต่อออกอินเทอร์เน็ตจะมีกล่องยินยอมบอกปลายทางและขนาดก่อน
รายละเอียดทั้งหมด (พาธจัดเก็บ ตั้งค่า quant/mmproj การโหลดต่อ การแก้ปัญหา ลิขสิทธิ์โมเดล): [docs/LOCAL-AI.md](docs/LOCAL-AI.md)

### Local AI ด้วย Ollama

1. ติดตั้ง [Ollama สำหรับ Windows](https://ollama.com/download/windows) และเปิดบริการ
2. เปิด Terminal แล้วดาวน์โหลดโมเดล Vision เช่น:
   ```powershell
   ollama pull qwen2.5vl:7b
   ```
3. ใน ScreenThai เลือก `Local AI · Ollama`
   - Base URL: `http://localhost:11434` **ไม่เติม `/api` หรือ `/v1`**
   - โมเดล: `qwen2.5vl:7b`
   - เปิด **ให้ AI ดูภาพหน้าจอ**
   - ไม่ต้องใส่ API key

โมเดลเป็นตัวอย่าง ไม่ใช่การรับรองคุณภาพภาษาไทยหรือความเข้ากันได้กับทุกเวอร์ชัน ตรวจว่าโมเดลที่ติดตั้งรองรับภาพและตอบ JSON ตามคำสั่งได้ โมเดลใหญ่ต้องใช้ RAM/VRAM มาก และจะแย่งทรัพยากรกับเกม การรันบน CPU อาจช้ามาก **ไม่รับประกัน 1–2 วินาที**

หากเครื่องช้า ให้เลือกพื้นที่เฉพาะซับ ลดจำนวนกล่อง หรือปิดดูภาพ แล้วเปลี่ยนเป็นโมเดลข้อความที่มีอยู่ เช่น `qwen2.5:7b` (ต้อง `ollama pull` แยก) เมื่อปิดภาพ AI จะใช้เฉพาะ OCR/บริบท ไม่เห็นคนหรือฉาก

### External API / LM Studio / OpenAI-compatible

เลือก `API · OpenAI-compatible / LM Studio` แล้วกรอก:

| บริการ | Base URL ตัวอย่าง | หมายเหตุ |
|---|---|---|
| OpenAI | `https://api.openai.com/v1` | ใส่ชื่อโมเดลที่บัญชีมีสิทธิ์และรองรับ Chat Completions |
| LM Studio ในเครื่อง | `http://localhost:1234/v1` | เปิด local server และโหลดโมเดลก่อน |
| บริการ compatible อื่น | ตามเอกสารบริการ รวม path เช่น `/v1` | แอปเติม `/chat/completions` ให้เอง |

- กรอก API key และชื่อโมเดลเอง ไม่มีการส่ง key ผ่าน URL
- เปิดดูภาพเฉพาะเมื่อโมเดลรองรับ image input; ปิดแล้วใช้ text-only ได้
- รองรับ **Ollama native API** และ **OpenAI-compatible Chat Completions** ไม่ใช่ Gemini/Anthropic native API โดยตรง
- ปลายทางนอก loopback ต้องใช้ **HTTPS** ไม่อนุญาต key/password/query ใน Base URL
- ก่อนเริ่มส่งไปนอกเครื่อง จะขออนุญาตพร้อมบอกปลายทางและชนิดข้อมูลทุกครั้ง
- ไม่มี automatic retry เมื่อ API error เพื่อไม่เรียกเก็บเงินซ้ำไม่รู้ตัว แอปหยุดและแสดงวิธีแก้

## ฟีเจอร์

- **Overlay บนเดสก์ท็อปจริง**: always-on-top, click-through, ข้อความไทยตัดบรรทัดด้วย Qt ปรับขนาดอักษรและความทึบแผ่นพื้นหลังได้
- **เลือกจอ/พื้นที่**: เลือกหนึ่งจอต่อรอบ รองรับการคำนวณพิกัดจอด้านซ้ายที่เป็นค่าลบและ DPI scaling; เมื่อการจัดจอเปลี่ยนจะหยุดเพื่อป้องกันจับผิดจอ
- **Local AI แบบ llama.cpp ในตัวแอป**: แท็บ *Local AI (llama.cpp)* ดาวน์โหลด `llama-server` จาก GitHub releases และโมเดล `.gguf` จาก Hugging Face ให้เอง (แสดงขนาด/ความคืบหน้า, โหลดต่อจากไฟล์ `.part` ได้, ยกเลิกได้, ตรวจ SHA-256 เมื่อมีให้ตรวจ) แล้วรันเซิร์ฟเวอร์ OpenAI-compatible บน **127.0.0.1 เท่านั้น** พร้อมปุ่ม *ตั้งเป็น AI ของแอป* — ไม่ต้องติดตั้ง Ollama หรือเครื่องมือภายนอก ([คู่มือ](docs/LOCAL-AI.md))
- **AI เลือกข้อความ**: ทั้งข้อความที่อ่านได้, เฉพาะบทสนทนา/ซับ, หรือข้อความสำคัญตามบริบท
- **AI ดูภาพ**: ส่ง sampled still พร้อม OCR boxes เพื่ออ่านฉาก ไม่ส่งวิดีโอ 60 FPS; ภาพส่ง AI ลดขนาดด้านยาวไม่เกิน 1280px ส่วน OCR อ่านภาพแยกในเครื่อง
- **บริบทแยกเกม**: notes ที่ยืนยันเอง, glossary, สรุปเรื่องต่อเนื่อง และความสัมพันธ์ที่มีหลักฐานข้อความ เก็บต่อหลังปิดโปรแกรมได้
- **อ่านสีหน้าจากการวัดโครงหน้า (ในเครื่อง)**: ตรวจใบหน้าด้วย mediapipe FaceMesh 478 จุด (ถ้าติดตั้ง `.[faces]`) หรือ OpenCV/ONNX ถ้ามี แล้ววัดช่องปาก มุมปาก ความเปิดตา ระยะคิ้ว การเอียงศีรษะและทิศทางสายตาเป็นตัวเลข; ภาพนิ่งภาพเดียวจะไม่ถูกเรียกว่าเป็นอารมณ์ แต่จะเทียบกับ baseline ของตัวละครคนนั้นเพื่อดู "การเปลี่ยน" แล้วให้โมเดลเดาอย่างระมัดระวังพร้อมบอกว่าเป็นการประมาณ
- **จำหน้าตัวละครข้ามเฟรมและข้ามรอบ**: tracker จับคู่กล่องด้วย IoU ให้ track id คงที่ระหว่างฉาก, descriptor และคลังหน้าแยกตามโปรไฟล์เกม; ชื่อจะถูกผูกกับหน้าเฉพาะเมื่อคุณกดยืนยัน คำแนะนำที่คะแนนไม่ถึงจะแสดงเป็น "ใบหน้า #N (อาจเป็น X)" เท่านั้น; เก็บเฉพาะเวกเตอร์กับสี ไม่เก็บภาพครอป
- **ตารางวิธีพูดรายตัวละคร**: กำหนดสรรพนามแทนตัวเอง/เรียกคู่สนทนา คำลงท้าย ระดับภาษา นิสัยการพูด และล็อกค่าไว้ได้; AI ได้แผนนี้เป็นคำสั่ง และใช้หลักฐานจากบทพูดจริง (คำสุภาพ คำเรียก อาวุโส) ก่อนการเดา
- **วิจัยเกมก่อนแปล**: ค้นเว็บผ่านผู้ให้บริการที่คุณตั้ง (SearXNG/Brave/Serper/Tavily/custom) และ/หรือลิงก์–ข้อความที่วางเอง สรุปเป็น brief (ชื่อ ฉาก ตัวละคร คำศัพท์ โทนเรื่อง) แทรกใน prompt ก่อนแปล; ต้องกดอนุญาตก่อนส่งคำค้นออกนอกเครื่อง และเก็บต่อโปรไฟล์ได้
- **กราฟตัวละคร**: ชื่อและเส้นความสัมพันธ์จากข้อสันนิษฐาน AI พร้อม tooltip หลักฐาน; การระบุตัวตนจากใบหน้าเป็นเพียง *คำแนะนำ* ที่รอผู้ใช้ยืนยัน ไม่ใช่ผลตรวจจริง
- **หน่วยความจำคำแปล (ต่อโปรไฟล์เกม)**: บรรทัดที่คุณยืนยันแล้วจะถูกใช้ซ้ำเมื่อข้อความเดิมปรากฏอีกครั้ง — ไม่เรียก AI ซ้ำ ไม่เสียเวลา/ค่าใช้จ่าย และไม่เปลี่ยนถ้อยคำเดิม; บรรทัดที่ขึ้นเตือน QC จะถูกเก็บไว้แต่ **ไม่** ใช้ซ้ำอัตโนมัติ และถ้าคุณแก้การ์ดเสียงของตัวละคร บรรทัดนั้นจะถูกส่งให้โมเดลแปลใหม่เพื่อไม่ให้ขัดกับการ์ด
- **ผสานบรรทัดซับที่ถูกตัดขึ้นบรรทัดใหม่**: บรรทัดต่อเนื่องของผู้พูดคนเดียวกันถูกรวมเป็นประโยคเดียวก่อนแปล (สูงสุด 3 บรรทัด) โดยใช้ตำแหน่ง/ป้ายชื่อ/เครื่องหมายจบประโยคเป็นหลักฐาน และ **ไม่แตะเมนูตัวเลือก** เพื่อไม่ให้ความหมายเปลี่ยน
- **ขุดคำศัพท์อัตโนมัติ**: ชื่อ/คำเฉพาะที่ซ้ำและคำไทยที่ใช้บ่อยจะถูกเสนอเป็นรายการ glossary พร้อมหลักฐาน — ยังไม่ถูกใช้จนคุณกดรับ (ตัดคำที่โผล่ในบรรทัดที่ไม่มีคำนั้นออก เพื่อไม่ให้เดา)
- **รอบตรวจความสม่ำเสมอ (opt-in)**: ถ้าบรรทัดใดใช้คำไม่ตรง glossary หรือขัดการ์ดที่ล็อกไว้ แอปจะให้ AI แก้ **เฉพาะบรรทัดที่ตั้งธง** พร้อมเหตุผลสั้น ๆ หนึ่งคำขอต่อรอบ และถ้ารอบนี้ล้มเหลวคำแปลเดิมจะไม่หาย
- **ตรวจสุขภาพระบบ**: ปุ่มตรวจที่บอกตรง ๆ ว่าอะไรใช้ได้/มีข้อจำกัด/ไม่ผ่าน/ตรวจไม่ได้ (OCR, ใบหน้า, ผังหน้าจอ, แผนการพูด, โฟลเดอร์ข้อมูล, ที่เก็บคีย์, ฟอนต์ไทย) พร้อมดึงรายชื่อโมเดลจาก Ollama/LM Studio มาเลือกใช้ได้โดยไม่ต้องพิมพ์เอง
- **เลือกสรรพนามไทยตามบริบท**: prompt ให้ข้อมูลที่ผู้ใช้ยืนยันสำคัญกว่าสิ่งที่ AI เดา ไม่ควรเดาเพศจากหน้าตา ผลยังขึ้นกับโมเดล
- **ไม่สะสมคิวภาพ**: OCR หนึ่งงาน + AI หนึ่งงานพร้อมกันได้ เก็บเฉพาะเฟรมล่าสุด แปลต่อเฉพาะ occurrence ที่ยังอยู่ ไม่เอาผลเก่ากลับมาทับหลังข้อความหายแล้วกลับมาใหม่
- **ประวัติ**: เก็บ 300 รายการล่าสุดใน RAM ส่งออก JSON ได้เมื่อผู้ใช้กดเอง
- **ถนอม key**: จำ key ได้ใน Windows Credential Manager หรือใช้เฉพาะใน RAM ไม่เก็บใน settings.json

### ปุ่มลัด (global บน Windows)

| ปุ่ม | การทำงาน |
|---|---|
| `Ctrl + Alt + T` | เริ่ม / หยุด |
| `Ctrl + Alt + H` | แสดง / ซ่อนคำแปล |
| `Ctrl + Alt + S` | แปลภาพปัจจุบันหนึ่งครั้ง เมื่อยังไม่กำลังแปล |
| `Esc` | ยกเลิกขณะลากพื้นที่ |

หน้าต่างจะย่อเมื่อเริ่มเพื่อไม่บังเกม เปิดกลับผ่าน taskbar หรือ system tray ปุ่มลัดไม่ใช้ keyboard hook หากซ้ำกับโปรแกรมอื่นใช้ปุ่มในหน้าต่างแทน

**แปลหนึ่งครั้ง** ใช้ภาพเดียวและคงคำแปลไว้จนซ่อน/เริ่มใหม่ เหมาะกับเมนูหรือหน้าที่อยู่นิ่ง ไม่ติดตามข้อความที่เปลี่ยนหลังจากนั้น

## ความเป็นส่วนตัว

- OCR และการวาด overlay ทำในเครื่องเสมอ ภาพอยู่ใน RAM ไม่บันทึก screenshot ลงดิสก์
- โหมดดูภาพส่งภาพของ **พื้นที่ที่เลือก** พร้อม OCR และบริบทให้บริการที่ตั้งไว้; text-only ยังส่งข้อความ OCR และบริบท
- Local Ollama และ llama.cpp ที่ `localhost`/`127.0.0.1` ไม่ส่งคำขอ inference ไปภายนอกผ่านแอปนี้ (การดาวน์โหลดโมเดล/ไฟล์เซิร์ฟเวอร์ครั้งแรกยังใช้อินเทอร์เน็ต)
- การดาวน์โหลดของ llama.cpp เชื่อมต่อเฉพาะโฮสต์ในรายการที่กำหนด (huggingface.co, cdn-lfs*.huggingface.co, hf.co, github.com, objects.githubusercontent.com, release-assets.githubusercontent.com) ผ่าน HTTPS และขอยินยอมก่อนทุกครั้ง ที่อ่านรายชื่อหรือดาวน์โหลด; เซิร์ฟเวอร์ในเครื่องเปิด web UI ปิด (`--no-webui`) และไม่ผูกกับที่อยู่ภายนอกเครื่อง
- สรุปเรื่อง/ความสัมพันธ์/notes/glossary เก็บเป็น JSON แบบอ่านได้ใน `%LOCALAPPDATA%\ScreenThai` **ไม่เข้ารหัส** อาจมีเนื้อหาบนหน้าจอที่ AI สรุปไว้
- ประวัติไม่บันทึกอัตโนมัติ แต่ไฟล์ที่ส่งออกอาจมีข้อมูลส่วนตัว
- แท็บบริบทมีปุ่มล้างสิ่งที่ AI เรียนรู้ ลบข้อมูลทั้งหมดได้โดยปิดแอปแล้วลบโฟลเดอร์ข้างต้น; key ที่จำไว้ลบแยกใน Windows Credential Manager หรือเอาเครื่องหมายจำ key ออกแล้วเริ่มรอบใหม่
- หลีกเลี่ยงแปลจอที่มีรหัสผ่าน ข้อมูลการเงิน หรือข้อความส่วนตัวโดยไม่จำเป็น

## ข้อจำกัดที่ต้องทราบ

1. **OCR รุ่นเริ่มต้นเน้นอังกฤษ/จีน** (RapidOCR bundled PP-OCR) ไม่รับประกันญี่ปุ่น/เกาหลี/อักษรเกมตกแต่ง แม้ AI จะแปลหลายภาษาได้ก็ไม่ช่วยเมื่อ OCR อ่านต้นฉบับไม่ได้
2. “ทั้งจอ” หมายถึงพื้นที่จับภาพ ไม่ใช่รับประกันแปลทุกพิกเซล มีเพดานเริ่มต้น 48 กล่อง/เฟรม ปรับได้ถึง 80 และ AI อาจข้ามส่วนอ่านไม่ออก/ข้อความไทยเดิม/ตัวเลขล้วน เลือกพื้นที่แคบลงหากข้อความมาก
3. คำแปลใช้แผ่นพื้นหลังทับข้อความเดิม ไม่ใช่การลบตัวอักษรหรือ inpainting หากข้อความไทยยาว แผ่นคำแปลอาจทับ UI/กล่องข้างเคียงหรือถูกตัดที่ขอบจอ
4. **ไม่มีการฟังเสียง/ASR/อ่านปาก และไม่มีการยืนยันผู้พูดจากวิดีโอ** การวิเคราะห์ใบหน้าเป็นการตรวจและวัดเชิงเรขาคณิตในเครื่อง ไม่ใช่ระบบยืนยันตัวตนหรือตัวตรวจจับอารมณ์ที่รับรองความแม่นยำ; ชื่อจะไม่ถูกผูกกับหน้าโดยไม่มีการยืนยันจากผู้ใช้ และไม่มีภาพ portrait ที่อ้างว่าจำหน้าได้เอง
5. ฉากอัปเดตเมื่อมีข้อความใหม่ที่ต้องแปล ไม่วิเคราะห์ฉากว่างต่อเนื่อง ความสัมพันธ์ที่เก็บมี threshold จากคะแนนที่โมเดลรายงานเอง ไม่ใช่ confidence ที่ calibrated
6. เฟรมที่มีข้อความหายไปก่อน AI ตอบจะถูกข้ามโดยตั้งใจ บทสนทนาที่เร็วกว่า inference จึงอาจไม่ได้แปล และคำเดิมที่ค้างอยู่จะไม่แปลใหม่จน occurrence เปลี่ยน
7. Windows exclusive fullscreen, DRM/protected content, secure desktop และบาง anti-cheat อาจบล็อก capture/overlay ไม่มีวิธี bypass ให้ใช้ Windowed/Borderless และปฏิบัติตามกฎเกม
8. โหมดจับภาพปลอดภัยซ่อน overlay ประมาณ 60ms ก่อน capture อาจเห็นกะพริบ โหมดทดลองใช้ `WDA_EXCLUDEFROMCAPTURE` ต้อง Windows 10 build 19041+ และบางระบบอาจได้พื้นที่ดำ/จับ overlay ซ้ำ ให้กลับไปโหมดปลอดภัย
9. เริ่มใหม่หลังหยุดต้องรอ request เก่าจบ/timeout การหยุดไม่สามารถเรียกคืนภาพที่ส่งไปแล้ว และการปิดแอปจะรอ worker จบอย่างปลอดภัย ไม่มีการ kill thread กลางงาน
10. ฟีเจอร์ใบหน้า/สีหน้าต้องติดตั้ง optional extra `pip install -e ".[faces]"` (mediapipe) ถ้าไม่ติดตั้ง แอปจะลดระดับเป็น OpenCV หรือปิดฟีเจอร์พร้อมบอกเหตุผล โดยการแปลและส่วนอื่นยังทำงานปกติ
11. คลังหน้า (เวกเตอร์+สีที่วัดได้) และตารางวิธีพูดถูกเก็บใน JSON ของโปรไฟล์แบบอ่านได้ **ไม่เข้ารหัส** ลบได้ด้วยการลบการ์ดหรือลบทั้งโฟลเดอร์ข้อมูล; ไม่มีการเก็บภาพหน้าจอหรือภาพครอปใบหน้าลงดิสก์
12. ข้อมูลจาก "วิจัยเกม" มาจากลิงก์ ผลการค้น และการสรุปของโมเดล อาจสับสนเกมชื่อคล้ายกันหรืออ้างข้อมูลแฟนคลับที่คลาดเคลื่อน จึงติดป้าย "ยังไม่ยืนยัน" จนกว่าคุณจะแก้ และไม่ใช้แทน glossary/notes ที่คุณยืนยันเอง
12.1 หน่วยความจำคำแปลใช้ข้อความต้นฉบับเป็นกุญแจ: ถ้าเกมเขียนต่างแม้แต่อักขระเดียวจะถือเป็นบรรทัดใหม่ และบรรทัดที่ซ้ำในบริบทต่างกัน (เช่น "ใช่" ในคำถามที่ต่างกัน) อาจถูกนำมาใช้ซ้ำตามตัวอักษร — ตั้ง `translation_memory` เป็น false ได้ในแท็บตั้งค่า
12.2 รอบตรวจความสม่ำเสมอเป็น *อีกหนึ่งคำขอ* ที่อาจมีค่าใช้จ่าย จึงปิดไว้เป็นค่าเริ่มต้นและจำกัดจำนวนบรรทัดต่อรอบ; การผสานบรรทัดอาจรวมสองประโยคเข้าด้วยกันผิดถ้าเกมไม่มีเครื่องหมายจบประโยค (ปิด `merge_lines` ได้)
12.3 การดาวน์โหลด llama.cpp/GGUF ในแอปเป็น *ตัวช่วยดาวน์โหลดและรัน* ไม่ใช่การรับรองโมเดล: ไฟล์โมเดลมีขนาดหลาย GB, **ไม่ได้ทดสอบดาวน์โหลด/รันจริงบน Windows ในรีโปนี้**, ไม่มีการอัปเดตอัตโนมัติ, ไม่มี UI ลบโมเดล (ลบไฟล์ในโฟลเดอร์ข้อมูลเอง), ไม่รับประกัน GPU/ความเร็วต่อการ์ดรุ่นใด, และน้ำหนักโมเดลมีใบอนุญาตต่างจากตัว llama.cpp (MIT) — ตรวจใบอนุญาตของ repo ที่เลือกเอง
13. Windows 10/11 **x64** เป็นเป้าหมาย Windows ARM/32-bit ไม่อยู่ในขอบเขตการทดสอบ

py -3.11 -m venv .venv
