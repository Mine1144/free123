## สิ่งที่พบ

EP1 อธิบายการให้ AI เลือกซับจากภาพเกม แปลเป็นไทยแล้วนำข้อความซ้อนใน OBS มีความหน่วงและข้ามบทสั้น พร้อมเน้นว่าความสัมพันธ์และลำดับอาวุโสมีผลกับสรรพนามไทย

EP2 เพิ่มสรุปสิ่งที่ AI เห็น (People / Place / Action), กราฟตัวละครและความสัมพันธ์, ข้อมูลตัวละคร, การพยายามระบุใบหน้าและการขยับปาก, การอนุมานผู้พูด/ผู้ฟัง, และใช้บทสนทนาเพื่อเรียนรู้บริบท ตัวอย่างในบทถอดเสียงยอมรับข้อผิดพลาด เช่น จับหลอดไฟ/เส้นผมเป็นหน้า เอาใบหน้าผู้ฟังไปเป็นผู้พูด และความหน่วงตามข้อจำกัดฮาร์ดแวร์ การกล่าวถึงเสียงไม่ได้ให้รายละเอียดเพียงพอที่จะยืนยันสถาปัตยกรรม audio pipeline ของต้นฉบับ

## ตารางความสามารถในเวอร์ชันนี้

| ความสามารถ | สถานะ | การทำงานจริง / ขอบเขต |
|---|---|---|
| AI เลือกข้อความที่ควรแปล | มี | ส่ง OCR IDs/boxes + scope ให้โมเดลตัดสินใจ |
| AI ดูภาพหน้าจอ | มี | ภาพนิ่งย่อขนาดเมื่อมีข้อความใหม่ ต้องใช้ Vision model |
| แปลเป็นไทยและใช้บริบท | มี | manual notes/glossary/เรื่องย่อ/ความสัมพันธ์ใน prompt |
| Overlay สำหรับผู้เล่น ไม่ใช่ OBS | มี | Qt transparent topmost window, click-through |
| ทั้งจอหรือเลือกพื้นที่ | มี | จอเดียวต่อรอบ ไม่ใช่ทุกจอพร้อมกัน |
| Local AI | มี | Ollama native `/api/chat`; ดาวน์โหลดโมเดลเอง |
| API key ภายนอก | มี | OpenAI-compatible `/chat/completions` |
| People / Place / Action | มี | ข้อสังเกตจาก AI ไม่ถือเป็นการระบุตัวตนที่ยืนยัน |
| จำบริบทข้ามการเปิดแอป | มี | JSON profiles แยกเกม |
| กราฟความสัมพันธ์ | มี | กราฟชื่อและเส้น hypothesis พร้อมหลักฐานใน tooltip |
| ยืนยัน/แก้สรรพนามเอง | มี | notes ที่มีลำดับสำคัญสูงกว่าสิ่งที่ AI สันนิษฐาน |
| ตรวจจับใบหน้าจากภาพนิ่ง | มี | ในเครื่อง: mediapipe FaceMesh (extra `.[faces]`) → OpenCV/Haar หรือ ONNX YuNet ถ้าผู้ใช้ตั้งไฟล์; ไม่ส่งภาพออก |
| อ่านสีหน้า | มี (จำกัด) | วัดเรขาคณิต (ช่องปาก/มุมปาก/ตา/คิ้ว/เอียงศีรษะ/สายตา) + trend เทียบ baseline ของตัวละครเอง; **ไม่ใช่** emotion classifier และไม่ฟันธงจากภาพเดียว |
| จำหน้าตัวละคร | มี (ผู้ใช้ยืนยัน) | tracker IoU + descriptor ในเครื่อง; ใช้ชื่อเมื่อผู้ใช้ยืนยัน (≥0.86 และชนะอันดับสอง ≥0.02), ต่ำกว่านั้นเป็น "อาจเป็น" หรือ "ไม่ทราบ"; เก็บเฉพาะเวกเตอร์+สี ไม่เก็บภาพ |
| วางแผนวิธีพูดรายตัวละคร | มี | การ์ดสรรพนาม/คำลงท้าย/ระดับภาษา/ความสัมพันธ์ + lock ที่ผู้ใช้ตั้ง; หลักฐานจากคำเรียกจริง อาวุโส และร่องรอยเพศจากถ้อยคำ |
| วิจัยเกมก่อนแปล | มี (opt-in) | ลิงก์ HTTPS/ข้อความที่วางเอง/ผู้ให้บริการค้นเว็บ; ขอยินยอมก่อนส่งคำค้น; สรุปเป็น brief ที่ติดป้าย "ยังไม่ยืนยัน" จนกว่าผู้ใช้แก้ |
| อ่านปาก/ยืนยันผู้พูดจากวิดีโอ | **ไม่มี** | ไม่วิเคราะห์วิดีโอต่อเนื่องหรือ lip-reading; track ใบหน้าใช้จับคู่กล่องเท่านั้น |
| ฟังเสียงเกม/ASR/แยกคนพูดด้วยเสียง | **ไม่มี** | อาศัยข้อความที่ OCR อ่านได้เท่านั้น (ใช้การขยับปากเป็นหลักฐานประกอบได้ แต่ไม่ใช่การยืนยัน) |
| ยืนยันตัวตน/ยืนยันอารมณ์แบบรับรองความแม่นยำ | **ไม่มี** | เป็นตัวช่วยจำและตัวชี้วัดในเครื่อง ไม่ใช่ biometric หรือเครื่องมือวินิจฉัย |
| วิเคราะห์เนื้อเรื่องช่วงไม่มีข้อความ | **ไม่มี** | ไม่ยิง Vision request ที่ไม่มี OCR blocks |
| Overlay ลบต้นฉบับแบบเนียน (inpainting) | **ไม่มี** | ทับด้วยแผ่นพื้นหลังปรับความทึบ |
| Latency ระดับ real-time รับประกัน | **ไม่มี** | ขึ้นกับเครื่อง โมเดล ภาพ และบริการ |

## เหตุผลการออกแบบ

- แยก OCR ในเครื่องเพื่อให้พิกัด overlay แน่นอน ไม่เชื่อพิกัดที่โมเดลสร้างขึ้น และให้ปิดส่งภาพได้
- AI ตอบ JSON; parser ไม่รับ ID ที่ไม่อยู่ใน OCR, ตัดซ้ำ, จำกัดขนาด และไม่ execute คำสั่งจากภาพหรือโมเดล
- OCR กับ inference อยู่คนละ worker thread ส่วน UI/capture/state อยู่ main thread มีเพียงหนึ่ง AI request ระหว่างทาง ไม่รัน request ซ้อนเมื่อเกมเปลี่ยนฉากเร็ว
- จับคู่ข้อความด้วยตำแหน่ง + เนื้อหา + occurrence token: HUD ที่เปลี่ยนตลอดไม่ทำให้ซับที่ยังอยู่แปลไม่ได้ และข้อความที่หายแล้วกลับมาใหม่ไม่รับผลเก่า
- ความสัมพันธ์ที่ AI รายงานต้องมีหลักฐานข้อความและคะแนน ≥0.8 จึงเก็บ แต่คะแนนนี้ยังอาจมั่นใจผิด การแสดงผลจึงเรียกว่า “ข้อสันนิษฐาน” เสมอ ไม่อนุมานเพศจากใบหน้า

## งานต่อไปเพื่อเข้าใกล้คลิป EP2 มากขึ้น

1. Audio loopback + local ASR แบบ opt-in, timestamp alignment และทดสอบเรื่องความเป็นส่วนตัว (ยังไม่ได้ทำ — เป็นช่องว่างหลักที่เหลือของ EP2)
2. ~~Fictional-character tracking หลายเฟรม พร้อม unknown state และการยืนยันตัวละครโดยผู้ใช้~~ **ทำแล้ว** (tracker + unknown/"อาจเป็น" + คิวยืนยัน; ยังต้องทดสอบกับเกมจริงหลายสไตล์กราฟิก)
3. ตรวจ speaker/listener โดยรวมหลักฐานข้อความ/การขยับปาก/ความต่อเนื่องของบท แต่ยัง **ไม่ใช้ “เห็นหน้า = กำลังพูด”** และไม่มีการยืนยันด้วยเสียง
4. OCR หลายภาษาให้เลือกและการรวมบรรทัดซับ ก่อนขยาย claim เรื่องภาษาต้นทาง
5. Windows capture backends เพิ่มเติมและทดสอบ exclusion จริงต่อ GPU/backend; signed installer และ onboarding ตรวจฮาร์ดแวร์
6. ทดสอบความแม่นยำของ descriptor/การวัดสีหน้ากับเกมจริง (การ์ตูน 3D, เซลเฉด, แสงกลางคืน) แล้วปรับ threshold จากข้อมูล ไม่ใช่จากภาพตัวอย่างไม่กี่ภาพ
